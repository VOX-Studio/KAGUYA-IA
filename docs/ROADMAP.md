# 🌙 Kaguya IA - Roadmap Officielle

> **Version** 1.0 | **Statut** Plan d'Implémentation Global 🗺️

---

## 📋 Vue d'ensemble

Cette roadmap définit les phases de développement de Kaguya, de la fondation technique jusqu'au système complet.

---

## 🏗️ PHASE 0 – Fondation du Projet

**Objectif :** Structure stable et base technique saine

### Tâches

- [ ] Arborescence complète créée
- [ ] EventBus central implémenté
- [ ] Logger central implémenté
- [ ] Chargement configuration globale
- [ ] Système de gestion threads initial

**Durée estimée :** 1-2 semaines

---

## 😊 PHASE 1 – Emotion Engine (Cœur Psychologique)

**Objectif :** Système émotionnel complet et fonctionnel

### Composants

- [ ] `ImmediateState`
- [ ] `EmotionalMark`
- [ ] `MoodBaseline` (drift long terme)
- [ ] `ReflectionEngine`
- [ ] Reinforcement system
- [ ] Bluff émotionnel
- [ ] Journal intime privé
- [ ] Logs émotionnels
- [ ] Anti-boucle d'ignorance

### Critères de validation

✅ L'ignorance volontaire est loggée  
✅ Le baseline ne se reset pas brutalement  
✅ Les marks persistent correctement  

**Durée estimée :** 2-3 semaines

---

## 💾 PHASE 2 – Memory System

**Objectif :** Système de mémoire structuré et persistant

### Composants

- [ ] `ShortTermMemory`
- [ ] `LongTermMemory`
- [ ] `KnowledgeMemory`
- [ ] `LifeEvents` (mémoire enfance)
- [ ] Système de priorisation
- [ ] Décroissance progressive
- [ ] Résumé périodique
- [ ] Persistence disque

### Critères de validation

✅ Les événements marquants persistent  
✅ La mémoire influence les réponses  
✅ Aucun accès direct aux fichiers hors MemoryManager  

**Durée estimée :** 2 semaines

---

## 🧠 PHASE 3 – Brain (LLM Integration)

**Objectif :** Intégration du modèle LLM et génération

### Composants

- [ ] Intégration modèle GGUF
- [ ] Injection contexte émotionnel
- [ ] Injection contexte mémoire
- [ ] Mode temps réel
- [ ] Mode qualité
- [ ] Interruption génération
- [ ] Multithreading stable

### Critères de validation

✅ Réponse prioritaire  
✅ Passage dynamique mode realtime/qualité  
✅ Contexte émotionnel correctement injecté  

**Durée estimée :** 2-3 semaines

---

## 🎤 PHASE 4 – Audio Pipeline

**Objectif :** Pipeline audio complet et optimisé

### Composants

- [ ] STT continu
- [ ] VAD (Voice Activity Detection)
- [ ] TTS streaming
- [ ] Interruption TTS si utilisateur parle
- [ ] Paramètres émotionnels vocaux
- [ ] Gestion latence naturelle
- [ ] Mode gaming

### Critères de validation

✅ Latence acceptable (< 500ms STT)  
✅ Interruption propre  
✅ Pas de phrases mécaniques type "je cherche"  

**Durée estimée :** 2-3 semaines

---

## ⚙️ PHASE 5 – Action System

**Objectif :** Capacités d'action système sécurisées

### Composants

- [ ] `ActionManager`
- [ ] Validation émotionnelle
- [ ] Audio control (volume, musique)
- [ ] Application control (ouvrir/fermer)
- [ ] Discord control (appels, micro)
- [ ] Cooldown system
- [ ] Logs actions
- [ ] Whitelist sécurité

### Critères de validation

✅ Action autonome loggée  
✅ Pas d'action critique autorisée par défaut  
✅ Cooldown fonctionnel  

**Durée estimée :** 1-2 semaines

---

## 🖥️ PHASE 6 – UI (Interface Utilisateur)

**Objectif :** Interface complète et intuitive

### Composants

- [ ] Interface principale conversation
- [ ] Paramètres modèles
- [ ] Profil utilisateur
- [ ] Onglet Debug
- [ ] Sélection périphériques audio
- [ ] Toggle multitâche
- [ ] Toggle wake word

### Critères de validation

✅ Nom utilisateur fonctionnel  
✅ Debug live opérationnel  
✅ Paramètres persistants  

**Durée estimée :** 2 semaines

---

## 📚 PHASE 7 – Study System

**Objectif :** Système d'apprentissage passif

### Composants

- [ ] Recherche Wikipedia
- [ ] Résumé automatique
- [ ] Checkpointing
- [ ] Interruption propre
- [ ] Synthèse journalière

### Critères de validation

✅ Interruption sans perte  
✅ Résumés de qualité  
✅ Checkpoints fonctionnels  

**Durée estimée :** 1-2 semaines

---

## 👁️ PHASE 8 – Presence System (Optionnel)

**Objectif :** Détection de présence et contexte visuel

### Composants

- [ ] Webcam
- [ ] Partage écran
- [ ] Détection présence
- [ ] Détection focus

**Durée estimée :** 1 semaine

---

## 🎭 PHASE 9 – VTuber (Dernier)

**Objectif :** Avatar animé et expressions visuelles

### Composants

- [ ] États animation
- [ ] Lip-sync
- [ ] Liaison émotionnelle
- [ ] Mouvement procédural

**Durée estimée :** 2-3 semaines

---

## ✅ Critères de Maturité

### Kaguya est considérée **"Stable v1"** lorsque :

| Phase | Statut |
|-------|--------|
| [ ] Emotion Engine | Complet et testé |
| [ ] Memory System | Stable |
| [ ] Brain + Audio | Fluides |
| [ ] Actions | Sécurisées |
| [ ] Logs | Complets |
| [ ] UI | Stable |
